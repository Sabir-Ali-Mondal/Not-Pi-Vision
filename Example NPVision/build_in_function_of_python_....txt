

<description>In Python, built-in functions are essential tools that are pre-defined and always accessible without any need for extra libraries. They help programmers perform common tasks easily, such as mathematical calculations, data conversions, or I/O operations. Examples include `len()` for getting the length of sequences, `print()` for outputting data, and `abs()` for absolute values.

These functions save time because they’re optimized and ready to use. When you type `len([1,2,3])`, Python instantly processes and returns `3` using its internal logic. Built-in functions cover various areas like type conversion (`int()`, `float()`), data structure creation (`list()`, `dict()`), mathematics (`min()`, `max()`, `sum()`), and many more.

Python’s built-in functions are written in C, making them very fast. Beginners rely on them to get quick results, while experts use them to keep code clean and efficient. They are fundamental in any Python program, forming the backbone of many scripts and applications.

Overall, Python built-in functions are:

1. Instantly usable without importing modules.
2. Versatile for different data types.
3. Time-saving and efficient.
4. Easy to learn yet powerful.
5. Continuously maintained and optimized in Python’s core system.

Mastering these functions is a crucial step for any Python learner, laying the groundwork for deeper programming concepts.</description>

function draw() {
  background(0, 10);
  stroke(0, 153, 255, 100);
  strokeWeight(2);
  noFill();
  ellipse(center.x, center.y, radius * 2);

    let angle = i * angleStep + frameCount * 0.002;
    let x = center.x + cos(angle) * radius;
    let y = center.y + sin(angle) * radius;
    fill(0, 102, 204);
    ellipse(x, y, 40 + sin(frameCount * 0.05 + i) * 5);
    fill(255);
    textSize(14);
    text(functions[i].name, x, y - 30);
    stroke(0, 102, 204, 150);
    line(center.x, center.y, x, y);
  }
  highlight();
}
function highlight() {
  let closest = null;
  let minDist = Infinity;
  for (let i = 0; i < functions.length; i++) {
    let angle = i * angleStep + frameCount * 0.002;
    let x = center.x + cos(angle) * radius;
    let y = center.y + sin(angle) * radius;
    let d = dist(mouseX, mouseY, x, y);
    if (d < 50 && d < minDist) {
      closest = functions[i];
      minDist = d;
    }
  }
  if (closest) {
    fill(0, 150);
    rect(mouseX + 15, mouseY + 15, 200, 50, 8);
    fill(255);
    textAlign(LEFT, TOP);
    textSize(12);
    text(closest.desc, mouseX + 25, mouseY + 25, 180);
  }
}
