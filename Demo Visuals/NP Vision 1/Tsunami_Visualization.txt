<description>
A tsunami is a series of ocean waves caused primarily by large undersea earthquakes at tectonic plate boundaries. When these massive shifts occur, a sudden vertical displacement of the seafloor displaces the overlying water column, generating waves that travel across the ocean at jetliner speeds, sometimes exceeding 800 kilometers per hour. While in deep water, tsunami waves may have small wave heights and long wavelengths, often passing unnoticed by ships. However, as these waves approach shallower coastal waters, their speed decreases and their height increases dramatically due to the compression of wave energy into a smaller volume of water. This amplification can result in devastating surges that inundate coastal areas with little warning.

Tsunamis are not caused solely by earthquakes; underwater landslides, volcanic eruptions, and even meteorite impacts can also trigger them. One of the deadliest tsunamis in recorded history occurred in the Indian Ocean in 2004, killing over 230,000 people across 14 countries. These events highlight the catastrophic potential of tsunamis and the critical importance of early warning systems and preparedness.

The behavior of tsunami waves is governed by principles of fluid dynamics and geophysics. When visualized, they can be seen as energy propagating radially from the disturbance point, with changes in seafloor elevation acting like a ripple-generating force. In educational contexts, 3D simulations and models are used to illustrate how tectonic plates shift, how water reacts, and how waves propagate and build up near shores. These scientific representations offer a clear and compelling way to understand the complexity and impact of these natural disasters.

</description>

  <script>
    let wave = [];
    let time = 0;
    let cols = 200;
    let rows = 200;
    let scale = 20;
    let w = 2000;
    let h = 2000;
    let angle = 0;
    let seed;

    function setup() {
      createCanvas(windowWidth, windowHeight, WEBGL);
      seed = millis();
      frameRate(30);
    }

    function draw() {
      background(1, 22, 39);
      rotateX(PI / 3);
      rotateZ(angle * 0.0003);
      translate(-w / 2, -h / 2);
      angle += 1;

      noiseSeed(seed);

      for (let y = 0; y < rows; y++) {
        wave[y] = [];
        for (let x = 0; x < cols; x++) {
          let distance = dist(x * scale, y * scale, cols / 2 * scale, rows / 2 * scale);
          let offset = map(distance, 0, 300, 0, PI);
          let z = map(sin(time - offset), -1, 1, -100, 100);
          wave[y][x] = z;
        }
      }

      time += 0.05;

      stroke(0, 150, 255, 100);
      noFill();
      for (let y = 0; y < rows - 1; y++) {
        beginShape(TRIANGLE_STRIP);
        for (let x = 0; x < cols; x++) {
          strokeWeight(1);
          let z1 = wave[y][x];
          let z2 = wave[y + 1][x];
          vertex(x * scale, y * scale, z1);
          vertex(x * scale, (y + 1) * scale, z2);
        }
        endShape();
      }
    }

    function resetSimulation() {
      seed = millis();
      time = 0;
    }

    document.body.innerHTML += '<button style="position:fixed;bottom:20px;right:20px;background:#07f;color:#fff;font-size:20px;border-radius:50%;width:30px;height:30px;border:none" name="replay" title="Replay">⟳</button>';
    document.querySelector('button[name="replay"]').onclick = resetSimulation;
  </script>
</body>
</html>
