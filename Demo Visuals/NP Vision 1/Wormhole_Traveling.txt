<description>  
Wormhole traveling refers to the theoretical passage through a shortcut in spacetime, potentially connecting distant parts of the universe or even different universes altogether. A wormhole, also known as an Einstein-Rosen bridge, is a solution to the Einstein field equations in general relativity. It represents a tunnel-like structure with two ends at separate points in spacetime. Conceptually, wormholes act like a tunnel through the fabric of space and time, allowing matter and information to traverse great cosmic distances almost instantaneously, compared to traditional space travel.

The idea of wormholes emerged from the general theory of relativity, where gravity is described as the curvature of spacetime caused by mass and energy. A wormhole can be imagined as a fold in a two-dimensional sheet representing space; if two points on the sheet are brought together and a tunnel is created through the third dimension, the shortcut represents a wormhole.

However, wormholes are still speculative. No observational evidence has yet confirmed their existence. Moreover, maintaining a stable wormhole open for travel would require exotic matter with negative energy density—a substance not known to exist in the required quantities. If such matter could exist, it might counteract the immense gravitational forces that would otherwise collapse the wormhole.

Theoretical wormholes come in various types: traversable wormholes (which allow safe passage of matter), non-traversable ones (often collapsing too quickly), and quantum wormholes (emerging from quantum gravity theories). Wormhole traveling holds promise for science fiction and advanced physics alike, offering tantalizing implications for faster-than-light travel and time travel. Despite current technological and physical limitations, the study of wormholes provides deep insight into the nature of spacetime, gravity, and the structure of the cosmos.

<script>
let angle = 0;
let particles = [];

function setup() {
  createCanvas(windowWidth, windowHeight, WEBGL);
  for (let i = 0; i < 300; i++) {
    particles.push(new Particle());
  }
}

function draw() {
  background(0);
  rotateY(angle * 0.5);
  rotateX(sin(angle * 0.3) * 0.3);

  // Wormhole tunnel
  noFill();
  stroke(100, 100, 255, 120);
  strokeWeight(1);
  for (let z = -500; z < 500; z += 20) {
    beginShape();
    for (let a = 0; a < TWO_PI; a += PI / 60) {
      let r = 80 + 50 * sin(z * 0.01);
      let x = r * cos(a);
      let y = r * sin(a);
      vertex(x, y, z);
    }
    endShape(CLOSE);
  }

  // Particles traveling through the wormhole
  for (let p of particles) {
    p.update();
    p.show();
  }

  angle += 0.01;
}

class Particle {
  constructor() {
    this.reset();
  }

  reset() {
    this.z = 500;
    this.angle = random(TWO_PI);
    this.r = random(50, 130);
    this.speed = random(2, 8);
    this.color = color(random(180, 255), random(180, 255), 255, 180);
  }

  update() {
    this.z -= this.speed;
    if (this.z < -500) this.reset();
  }

  show() {
    let x = this.r * cos(this.angle + this.z * 0.01);
    let y = this.r * sin(this.angle + this.z * 0.01);
    push();
    translate(x, y, this.z);
    noStroke();
    fill(this.color);
    sphere(2);
    pop();
  }
}

function windowResized() {
  resizeCanvas(windowWidth, windowHeight);
}
