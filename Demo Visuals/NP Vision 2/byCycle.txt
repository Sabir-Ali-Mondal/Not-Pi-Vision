<description>
The "byCycle" (bicycle) is a complex electromechanical system, fundamentally a human-powered vehicle designed for efficient locomotion. From a scientific perspective, its operation integrates principles of classical mechanics, human physiology, and control theory. Mechanically, it functions as a compound machine utilizing levers (pedals and cranks), wheels and axles, and a chain-driven gear system (derailleurs) to convert rotational torque into linear motion. The rider's chemical energy is transformed into kinetic energy of the bicycle.

Physically, the bicycle's dynamic stability, a hallmark of its design, is achieved through a combination of geometric factors like `trail` and `castor angle` (which impart a self-centering tendency to the front wheel), and the `gyroscopic effect` of the spinning wheels, especially at higher speeds. The latter contributes to the bicycle's resistance to tipping due to the conservation of angular momentum. Propulsion relies on the static friction between the tires and the ground, translating the wheels' rotational force into forward thrust as per Newton's Third Law. Aerodynamics also plays a significant role, particularly at speed, influencing drag and overall efficiency.

From a control theory standpoint, the human rider acts as the primary feedback control system. They continuously adjust their center of mass and employ `counter-steering`—a nuanced steering input opposite to the desired turn to initiate lean—to maintain dynamic equilibrium. Braking systems convert the bicycle's kinetic energy into thermal energy through friction, using mechanical advantage to efficiently decelerate or stop the vehicle. The synergistic interaction of these components makes the bicycle a sophisticated and highly optimized system for personal transport.

        function draw() {
            background(getComputedStyle(document.documentElement).getPropertyValue('--bg-color'));

            push();
            // Scale and translate the entire drawing to fit the canvas and be responsive
            let scaleFactor = min(width / 1200, height / 700); // Base dimensions for bike: ~1000x500

                let elapsedTime = millis() - slideStartTime;
                animationProgress = constrain(elapsedTime / slideDurations[currentSlide], 0, 1);
            } else if (!isNarrating) {
                 // If not narrating, animation on current slide should still progress for visual replay
                 let elapsedTime = millis() - slideStartTime;
                 animationProgress = constrain(elapsedTime / slideDurations[currentSlide], 0, 1);
                 // If a slide duration finishes without narration, advance it.
                 // This ensures replay works even if narration isn't playing.
                 if (animationProgress >= 1 && currentSlide < slideDurations.length - 1) {
                     currentSlide++;
                     slideStartTime = millis();
                     animationProgress = 0;
                 } else if (animationProgress >= 1 && currentSlide === slideDurations.length - 1) {
                     // Last slide finished, loop back to intro for replay visual
                     currentSlide = 0;
                     slideStartTime = millis();
                     animationProgress = 0;
                 }
            }


            // Draw the current slide based on `currentSlide` and `animationProgress`
            drawSlide(currentSlide);

            pop();
        }

                        const contactPointY = frontWheelY + wheelRadius;
                        drawBlueprintCircle(contactPointX, contactPointY, 5, 2, glowColor()); // Contact point
                        drawBlueprintText("Contact Point", contactPointX, contactPointY + 20, 14, glowColor(), CENTER);

                        // Trail
                        let trailLength = (steeringAxisExtensionX - contactPointX) * animationProgress; // Animate trail emergence
                        if (highlightedElement === 'frontFork') trailLength = steeringAxisExtensionX - contactPointX; // Fixed for highlight
                        drawBlueprintLine(contactPointX, contactPointY, contactPointX + trailLength, contactPointY, 2, glowColor(), true);
                        drawBlueprintText("Trail", contactPointX + trailLength / 2, contactPointY + 30, 14, glowColor(), CENTER);

                        // Simulate small counter-steer
                        if (highlightedElement === 'steeringBalance') {
                            push();
                            translate(frontWheelX, frontWheelY);
                            rotate(sin(millis() * 0.1) * 5 * animationProgress); // Subtle wobble for steering
                            drawBlueprintText("Rider Input", -100, -100, 18, glowColor(), CENTER);
                            pop();
                        }
                    }
                    break;

                case 4: // Gyroscopic Stability
                    drawBlueprintText("4. Gyroscopic Stability", 500, 50, 30, textColor(), CENTER);
                    drawBlueprintText("Spinning wheels resist changes in orientation", 500, 90, 16, textColor(), CENTER);

                    if (highlightedElement === 'wheelsGyroscopic') {
                        const wheelRadius = 100;
                        const frontWheelX = 280;
                        const frontWheelY = 350;
                        const rearWheelX = 750;
                        const rearWheelY = 350;

                        // Highlight fast rotation
                        drawBlueprintText("Angular Momentum", frontWheelX, frontWheelY - 120, 18, glowColor(), CENTER);
                        drawBlueprintText("Angular Momentum", rearWheelX, rearWheelY - 120, 18, glowColor(), CENTER);

                        // Conceptual stability arrows (resisting tilt)
                        let arrowLen = 50 * animationProgress;
                        drawArrow(frontWheelX, frontWheelY, frontWheelX + arrowLen, frontWheelY - arrowLen/2, 10, glowColor(), 3);
                        drawArrow(frontWheelX, frontWheelY, frontWheelX - arrowLen, frontWheelY + arrowLen/2, 10, glowColor(), 3);
                        drawBlueprintText("Stability Force", frontWheelX, frontWheelY + 150, 14, glowColor(), CENTER);

                        drawArrow(rearWheelX, rearWheelY, rearWheelX + arrowLen, rearWheelY - arrowLen/2, 10, glowColor(), 3);
                        drawArrow(rearWheelX, rearWheelY, rearWheelX - arrowLen, rearWheelY + arrowLen/2, 10, glowColor(), 3);
                        drawBlueprintText("Stability Force", rearWheelX, rearWheelY + 150, 14, glowColor(), CENTER);
                    }
                    break;

                case 5: // Braking System
                    drawBlueprintText("5. Braking System", 500, 50, 30, textColor(), CENTER);
                    drawBlueprintText("Kinetic Energy → Thermal Energy via Friction", 500, 90, 16, textColor(), CENTER);

                    if (highlightedElement === 'brakes') {
                        const rearWheelX = 750;
                        const rearWheelY = 350;
                        const wheelRadius = 100;

                        // Show brake force
                        let forceLen = 40 * animationProgress;
                        drawArrow(rearWheelX + wheelRadius + 20, rearWheelY - 20, rearWheelX + wheelRadius + 20, rearWheelY - 20 - forceLen, 10, glowColor(), 3);
                        drawBlueprintText("Lever Force", rearWheelX + wheelRadius + 20, rearWheelY - 80, 14, glowColor(), CENTER);

                        drawArrow(rearWheelX, rearWheelY - wheelRadius - 20, rearWheelX, rearWheelY - wheelRadius - 20 - forceLen, 10, glowColor(), 3);
                        drawBlueprintText("Caliper Force", rearWheelX, rearWheelY - wheelRadius - 80, 14, glowColor(), CENTER);
                    }
                    break;

                case 6: // Conclusion
                    drawBlueprintText("THE BYCYCLE: AN INTEGRATED SYSTEM", 500, 50, 30, textColor(), CENTER);
                    drawBlueprintText("Seamlessly integrating Physics, Mechanics, and Human Input for Efficient Locomotion.", 500, 90, 16, textColor(), CENTER);
                    drawBlueprintText("Power Transmission • Propulsion • Steering • Balance • Stability • Braking", 500, 130, 14, textColor(), CENTER);
                    drawBlueprintText("Thank you for exploring the science of cycling!", 500, 550, 20, textColor(), CENTER);

                    // A subtle pulse effect for the entire bicycle
                    if (highlightedElement === 'bicycle') {
                        stroke(glowColor());
                        strokeWeight(2 + sin(millis() * 0.005) * 1); // Pulse effect
                        noFill();
                        rect(100, 100, 800, 400); // Outline around the whole bike
                    }
                    break;
            }
        }
