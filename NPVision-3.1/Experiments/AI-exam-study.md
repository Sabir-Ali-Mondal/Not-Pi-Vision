# ✅ **AI Syllabus → Question Verification → Topic List → Theory Notes Workflow**

---

# **STEP 1 — Give Syllabus (Input)**

**Your Action:**
Paste the *entire syllabus* exactly as written in PDF/text.

**Prompt to use:**

```
Here is my syllabus. Clean it, arrange chapterwise, and ensure every topic is captured clearly without adding anything extra.
```

---

# **STEP 2 — Generate Question List From Notebook (Input)**

**Your Action:**
Copy all questions from your notebook or PDF and paste them.

**Prompt to use:**

```
Here are my collected questions. Clean them, remove duplicates, arrange chapterwise, and ensure alignment with the syllabus.
```

---

# **STEP 3 — Verification Against Syllabus (AI Action)**

**Your Action:**
Ask AI to check if the question list matches the syllabus.

**Prompt to use:**

```
Verify whether this question list fully matches the syllabus. 
Identify missing topics, extra topics, and correct the list.
```

**AI Output:**
A corrected and syllabus-matched question list.

---

# **STEP 4 — Convert Question List → Theory Topics (Organised)**

**Your Action:**
Now convert verified questions into chapterwise theory topics.

**Prompt to use:**

```
Convert this verified question list into a clean chapter-wise list of theoretical topics only. 
Do not add anything extra beyond the syllabus.
```

---

# **STEP 5 — Generate Calculative/Skill Topics + YouTube Keywords**

**Your Action:**
Generate the skill-based topics separately.

**Prompt to use:**

```
List all calculative and skill-based topics separately. 
Convert them into short YouTube search keywords (not long phrases).
```

---

# **STEP 6 — Generate 100-Word Theory Notes (Next Step)**

This is your next target.

**Your Action:**
Take each theory topic one by one or in groups.

**Prompt to use (final stage):**

```
Generate a 100-word explanation for each of these theory topics. 
Use pointwise format, clear language, and simple exam-style writing.
Do not exceed 100 words per topic.
```

Example:

```
Generate 100-word notes for:
1. Intelligent Agents
2. Hill Climbing
3. Bayesian Networks
```

---

# **STEP 7 — (Optional) Create SVG Diagrams**

If needed for exam visuals.

**Prompt:**

```
Create an SVG diagram for each of these topics:
(then list the topics)
```

---

# **STEP 8 — (Optional) Create 1-page Revision Sheet**

**Prompt:**

```
Create a one-page revision sheet for this chapter using only syllabus topics.
```
