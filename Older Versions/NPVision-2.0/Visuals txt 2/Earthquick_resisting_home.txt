<description>
An "earthquake resisting home" is a structure engineered and constructed to withstand the destructive forces generated by seismic events, significantly reducing the risk of collapse and minimizing damage to life and property. Unlike conventional buildings designed primarily for vertical loads, earthquake-resistant structures incorporate specific principles of seismic design to absorb, dissipate, or redirect the kinetic energy imparted by ground motion.

Scientifically, this involves principles from structural dynamics and material science. Key strategies include:
1.  **Base Isolation:** This involves decoupling the building's superstructure from its foundation using flexible bearings (e.g., laminated rubber bearings, friction pendulum systems). When seismic waves hit, the ground moves significantly, but the isolators deform, extending the building's natural period of vibration. This shifts the building's response away from the dominant frequencies of earthquake ground motion, reducing the forces transmitted into the structure above. The building moves as a rigid body on the isolators, experiencing much less internal deformation.
2.  **Energy Dissipation Devices (Dampers):** Analogous to shock absorbers, these devices are integrated into the structural frame to absorb seismic energy. Examples include viscous fluid dampers (which convert kinetic energy into heat through fluid friction), metallic yield dampers (which deform plastically), and friction dampers. They reduce the amplitude of structural vibrations and provide additional damping, preventing resonant build-up of forces.
3.  **Structural Ductility:** Rather than designing brittle structures that fail suddenly, earthquake-resistant buildings utilize ductile materials (like specific grades of steel and reinforced concrete with proper rebar detailing) and connections that can undergo large inelastic deformations without fracturing. This allows the structure to yield gracefully under extreme loads, dissipating energy through plastic deformation and providing warning signs of distress, thereby preventing catastrophic collapse.
4.  **Lateral Load Resisting Systems:** This includes:
    *   **Shear Walls:** Stiff, vertical elements (reinforced concrete or masonry) designed to resist horizontal forces (shear) from earthquakes, transferring them down to the foundation. They act like deep, vertical beams.
    *   **Moment-Resisting Frames:** Beams and columns are rigidly connected to form "frames" that resist lateral forces by bending. The strength and ductility of these connections are crucial.
    *   **Braced Frames:** Incorporate diagonal members (braces) that form a truss system, providing stability and stiffness against lateral loads.
5.  **Tuned Mass Dampers (TMDs):** Primarily used in tall buildings, a large mass is mounted on springs and dampers within the structure, tuned to oscillate out of phase with the building's natural frequency. This counteracts the building's sway, reducing accelerations and displacements, particularly in high winds or moderate seismic events.

An integrated approach combining these techniques, along with rigorous site-specific seismic hazard analysis and adherence to stringent building codes, forms the foundation of modern earthquake-resistant home design, ensuring structural integrity and human safety during seismic events.

            rect(0, tmdY, tmdWidth, tmdHeight);
            line(-buildingWidth / 2, -buildingHeight, -tmdWidth / 2, tmdY + tmdHeight / 2);
            line(buildingWidth / 2, -buildingHeight, tmdWidth / 2, tmdY + tmdHeight / 2);
        }

        // --- Narration Functions ---
        function getVoice(gender) {
            let filteredVoices = voices.filter(voice => voice.lang.startsWith('en-')); // More general English filter
            if (gender === 'male') {
                return filteredVoices.find(voice => voice.name.toLowerCase().includes('male') || voice.name.toLowerCase().includes('david') || voice.name.toLowerCase().includes('us')) || filteredVoices[0];
            } else { // female
                return filteredVoices.find(voice => voice.name.toLowerCase().includes('female') || voice.name.toLowerCase().includes('zira') || voice.name.toLowerCase().includes('us')) || filteredVoices[1] || filteredVoices[0];
            }
        }

        function startNarration() {
            if (isNarrating) return;
            isNarrating = true;
            currentUtteranceIndex = -1;
            narrationQueue = [...narrationScript]; // Copy script to queue
            playNextNarration();
            isAnimating = true; // Start visual animation with narration
        }

        function stopNarration() {
            if (synth) {
                synth.cancel();
            }
            isNarrating = false;
            highlightedElement = 'none'; // Clear highlight
            if (highlightTimeout) clearTimeout(highlightTimeout); // Clear any pending highlights
            // Visuals continue to play or stop based on their own logic if not narrated.
        }

        function playNextNarration() {
            if (!isNarrating) return;

            currentUtteranceIndex++;
            if (currentUtteranceIndex < narrationQueue.length) {
                const item = narrationQueue[currentUtteranceIndex];
                const utterance = new SpeechSynthesisUtterance(item.text);

                utterance.voice = getVoice(item.voice);
                utterance.pitch = item.pitch;
                utterance.rate = item.rate;

                utterance.onstart = () => {
                    currentSlide = item.slide;
                    highlightedElement = item.highlight;
                    currentFrame = 0; // Reset frame counter for new slide animation
                    console.log(`Starting slide ${currentSlide}, highlighting ${highlightedElement}`);

                    if (highlightTimeout) clearTimeout(highlightTimeout);
                    highlightTimeout = setTimeout(() => {
                        if (highlightedElement === item.highlight) {
                            highlightedElement = 'none';
                        }
                    }, 5000); // Highlight for 5 seconds by default
                };

                utterance.onend = () => {
                    playNextNarration();
                };

                synth.speak(utterance);
            } else {
                // Narration finished
                stopNarration();
                // After narration, keep the last slide for a moment then reset
                setTimeout(() => { resetAnimation(); }, 2000);
            }
        }

        // --- Control Buttons ---
        document.getElementById('replay').addEventListener('click', () => {
            stopNarration(); // Stop any ongoing narration
            resetAnimation(); // Reset and start visual animation
            isAnimating = true; // Ensure visual animation starts
        });

        document.getElementById('podcast').addEventListener('click', () => {
            if (isNarrating) {
                stopNarration();
            } else {
                resetAnimation(); // Reset visuals before starting narration
                startNarration();
            }
        });

        function resetAnimation() {
            currentSlide = 0;
            currentFrame = 0;
            animationProgress = 0;
            groundShakeOffset = 0;
            shakeAmplitude = 0;
            shakeFrequency = 0;
            buildingSwayOffset = 0;
            buildingSwayAmplitude = 0;
            buildingSwayFrequency = 0;
            highlightedElement = 'none';
            isAnimating = false; // By default, animation is paused when reset, until replay/podcast starts it
        }

    </script>
