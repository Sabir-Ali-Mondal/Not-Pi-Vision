India's Gross Domestic Product (GDP) growth graph from 2000 onwards illustrates a dynamic and complex economic trajectory, reflecting both domestic policy shifts and global economic forces. Following the foundational economic liberalizations of the 1990s, the early 2000s saw India establish a growth momentum, characterized by expansion in the services sector, particularly IT. This period transitioned into a sustained high-growth phase from approximately 2003 to 2007, with annual GDP growth rates often exceeding 8-9%. This acceleration was fueled by robust capital inflows, strong domestic consumption, increasing industrial output, and a favorable global economic climate.

The global financial crisis of 2008-2009 presented a significant external shock, causing a sharp but brief deceleration in India's growth. However, strong domestic fundamentals and timely fiscal and monetary stimuli facilitated a relatively quick V-shaped recovery, with growth rebounding sharply in 2009-2010. The subsequent decade (2010s) brought new challenges: global economic moderation, high domestic inflation, and later, the disruptive effects of major structural reforms like demonetization (2016) and the Goods and Services Tax (2017), which caused temporary slowdowns. The pre-pandemic years saw growth moderate further due to a credit crunch in the financial sector and a general global slowdown.

The most dramatic event was the COVID-19 pandemic in 2020, leading to an unprecedented contraction in economic activity. Post-2020, India has again demonstrated remarkable resilience, achieving one of the fastest major economy recoveries, driven by renewed consumption, government infrastructure spending, and a rebound in manufacturing and services, positioning itself for continued robust growth into the mid-2020s. Analyzing this graph scientifically requires understanding the interplay of domestic policy, global cycles, and structural economic changes.

        // P5.js sketch variables
        let canvasWidth, canvasHeight;
        let chartX, chartY, chartW, chartH;
        let data = []; // To store GDP growth data
        let minYear = 2000;
        let maxYear = 2023;
        let minGDP = -8; // Adjusted for COVID-19 contraction
        let maxGDP = 12; // Adjusted for higher growth years

        let currentAnimationYear = minYear;
        let animationProgress = 0; // 0 to 1, for drawing the current year's line segment
        let animationSpeed = 0.01; // Speed of drawing the graph line per frame (when not narrating)
        let currentHighlight = null; // Object { startYear, endYear } for narration highlights

        // Narration variables
        let narrationStatements = [];
        let currentNarrationIndex = 0;
        let isNarrating = false;
        let utterance = null;
        let voices = [];
        let speakerA, speakerB;

        function preload() {
            // Simulated India GDP Growth Rates (Annual Percentage Change)
            // Data sourced roughly from general economic trends, not exact figures.

            ];

            narrationStatements = [

                { text: "This visualization will highlight key phases and economic events that shaped its trajectory.", speaker: 'B', highlight: null },
                { text: "In the early 2000s, India experienced a steady rise, building on liberalization efforts from the previous decade, establishing a robust growth momentum.", speaker: 'A', highlight: { startYear: 2000, endYear: 2004 } },
                { text: "The mid-2000s, particularly from 2005 to 2007, saw an unprecedented boom. This period was driven by robust global growth, increased investment, and strong domestic demand.", speaker: 'B', highlight: { startYear: 2005, endYear: 2007 } },
                { text: "However, the global financial crisis of 2008-2009 significantly impacted India, causing a sharp deceleration, though it managed a quick recovery.", speaker: 'A', highlight: { startYear: 2008, endYear: 2009 } },

                { text: "Major structural reforms like demonetization in late 2016 and the Goods and Services Tax in 2017 introduced short-term disruptions, momentarily dampening growth.", speaker: 'B', highlight: { startYear: 2016, endYear: 2017 } },
                { text: "The period leading up to 2020 saw a gradual slowdown, influenced by both domestic financial sector issues and a general global deceleration.", speaker: 'A', highlight: { startYear: 2018, endYear: 2019 } },
                { text: "Then came the unprecedented challenge of the COVID-19 pandemic in 2020, leading to a significant contraction of the economy, a truly exceptional event.", speaker: 'B', highlight: { startYear: 2020, endYear: 2020 } },
                { text: "Remarkably, India demonstrated a strong V-shaped recovery post-pandemic, leveraging policy support and pent-up demand to achieve high growth rates in 2021 and 2022.", speaker: 'A', highlight: { startYear: 2021, endYear: 2023 } },
                { text: "This period highlights India's inherent resilience, driven largely by robust domestic consumption and public capital expenditure, positioning it for future growth.", speaker: 'B', highlight: { startYear: 2021, endYear: 2023 } },
                { text: "And that concludes our detailed scientific overview of India's GDP growth journey from 2000.", speaker: 'A', highlight: null }
            ];
        }

        function setup() {
            canvasWidth = window.innerWidth * 0.8;
            canvasHeight = window.innerHeight * 0.8;
            let canvas = createCanvas(canvasWidth, canvasHeight);
            canvas.id('p5Canvas'); // Assign ID for CSS targeting

            // Calculate chart dimensions and padding
            let padding = min(canvasWidth, canvasHeight) * 0.1;
            chartX = padding;
            chartY = padding;
            chartW = canvasWidth - 2 * padding;
            chartH = canvasHeight - 2 * padding;

            frameRate(30); // Fixed frame rate at 30 FPS

            // Initialize SpeechSynthesis
            if ('speechSynthesis' in window) {
                const setVoices = () => {
                    voices = window.speechSynthesis.getVoices();
                    // Attempt to find specific voices, fallback to general English, then first available
                    speakerA = voices.find(voice => voice.name.includes('Google') && voice.lang.includes('en-') && (voice.name.includes('Female') || voice.gender === 'female')) ||
                               voices.find(voice => voice.lang.includes('en-US') && (voice.gender === 'female' || voice.name.includes('Female'))) || voices[0];
                    speakerB = voices.find(voice => voice.name.includes('Google') && voice.lang.includes('en-') && (voice.name.includes('Male') || voice.gender === 'male')) ||
                               voices.find(voice => voice.lang.includes('en-GB') && (voice.gender === 'male' || voice.name.includes('Male'))) || voices[1] || voices[0];

                    if (!speakerA) speakerA = voices[0];
                    if (!speakerB) speakerB = voices[1] || voices[0]; // Fallback if only one voice or no specific match
                };
                window.speechSynthesis.onvoiceschanged = setVoices;
                setVoices(); // Call immediately in case voices are already loaded
            } else {
                console.warn("SpeechSynthesis API not supported in this browser.");
                document.getElementById('podcast').style.display = 'none'; // Hide button if not supported
            }

            document.getElementById('replay').addEventListener('click', resetVisuals);
            document.getElementById('podcast').addEventListener('click', toggleNarration);

            resetVisuals(); // Initial reset
        }

        function windowResized() {
            canvasWidth = window.innerWidth * 0.8;
            canvasHeight = window.innerHeight * 0.8;
            resizeCanvas(canvasWidth, canvasHeight);
            let padding = min(canvasWidth, canvasHeight) * 0.1;
            chartX = padding;
            chartY = padding;
            chartW = canvasWidth - 2 * padding;
            chartH = canvasHeight - 2 * padding;
            // No resetVisuals here to prevent re-starting animation on every resize.
            // Just update drawing dimensions.
        }

        function draw() {
            background(getComputedStyle(document.documentElement).getPropertyValue('--bg-color'));

            drawGlassmorphismBorder();
            drawGrid();
            drawAxes();
            drawChart();
            drawLabels();

            if (!isNarrating) {
                // If not narrating, continuously advance animation to show full graph
                if (currentAnimationYear < maxYear || (currentAnimationYear === maxYear && animationProgress < 1)) {
                    animationProgress += animationSpeed; // Advance progress within current year segment
                    if (animationProgress >= 1) {
                        currentAnimationYear++; // Move to next year
                        animationProgress = 0; // Reset progress for the new year segment
                        if (currentAnimationYear > maxYear) { // Cap at max year once done
                            currentAnimationYear = maxYear;
                            animationProgress = 1;
                        }
                    }
                }
            }
        }

        function drawGlassmorphismBorder() {
            noFill();
            let glassBorderColor = getComputedStyle(document.documentElement).getPropertyValue('--glass-border');
            let glowColor = getComputedStyle(document.documentElement).getPropertyValue('--glow-color');

            stroke(glassBorderColor);
            strokeWeight(1.5);
            rect(0, 0, canvasWidth, canvasHeight, 15); // Draw border with rounded corners

            drawingContext.shadowOffsetX = 0;
            drawingContext.shadowOffsetY = 0;
            drawingContext.shadowBlur = 20;
            drawingContext.shadowColor = glowColor;

            stroke(glowColor);
            strokeWeight(0.5);
            rect(0, 0, canvasWidth, canvasHeight, 15); // Inner glow
            drawingContext.shadowBlur = 0; // Reset shadow
        }

        function drawGrid() {
            stroke(255, 255, 255, 30); // Light grey, semi-transparent
            strokeWeight(0.5);

            // Horizontal grid lines (GDP values)
            let gdpStep = 2; // Draw lines every 2% GDP growth
            for (let g = floor(minGDP / gdpStep) * gdpStep; g <= maxGDP; g += gdpStep) {
                let y = map(g, minGDP, maxGDP, chartY + chartH, chartY);
                line(chartX, y, chartX + chartW, y);
            }

            // Vertical grid lines (Years)
            let numYears = maxYear - minYear + 1;
            let yearInterval = (numYears > 15) ? 2 : 1; // Show every other year if too many
            for (let i = 0; i < numYears; i++) {
                let year = minYear + i;
                if (year % yearInterval === 0 || year === minYear || year === maxYear) {
                    let x = map(year, minYear, maxYear, chartX, chartX + chartW);
                    line(x, chartY, x, chartY + chartH);
                }
            }
        }

        function drawAxes() {
            stroke(getComputedStyle(document.documentElement).getPropertyValue('--text-color'));
            strokeWeight(1.5);

            // X-axis (Years)
            line(chartX, chartY + chartH, chartX + chartW, chartY + chartH);
            // Y-axis (GDP Growth %)
            line(chartX, chartY, chartX, chartY + chartH);

            fill(getComputedStyle(document.documentElement).getPropertyValue('--text-color'));
            noStroke();
            textSize(chartW * 0.02);
            textAlign(CENTER, TOP);

            // X-axis labels
            let numYears = maxYear - minYear + 1;
            let yearInterval = (numYears > 15) ? 2 : 1;
            for (let i = 0; i < numYears; i++) {
                let year = minYear + i;
                if (year % yearInterval === 0 || year === minYear || year === maxYear) {
                    let x = map(year, minYear, maxYear, chartX, chartX + chartW);
                    text(year, x, chartY + chartH + 10);
                }
            }

            textAlign(RIGHT, CENTER);
            // Y-axis labels
            let gdpStep = 2;
            for (let g = floor(minGDP / gdpStep) * gdpStep; g <= maxGDP; g += gdpStep) {
                let y = map(g, minGDP, maxGDP, chartY + chartH, chartY);
                text(g + '%', chartX - 10, y);
            }

            // Axis titles
            textAlign(CENTER, BOTTOM);
            textSize(chartW * 0.025);
            text("Year", chartX + chartW / 2, chartY + chartH + 40);
            push();
            translate(chartX - 50, chartY + chartH / 2);
            rotate(-HALF_PI);
            text("Annual GDP Growth (%)", 0, 0);
            pop();
        }

        function drawChart() {
            noFill();
            let primaryColor = getComputedStyle(document.documentElement).getPropertyValue('--primary-color');
            let highlightColor = getComputedStyle(document.documentElement).getPropertyValue('--highlight-color');
            let textColor = getComputedStyle(document.documentElement).getPropertyValue('--text-color');
            let glowColor = getComputedStyle(document.documentElement).getPropertyValue('--glow-color');

            if (data.length === 0) return;

            let prevX, prevY;
            for (let i = 0; i < data.length; i++) {
                let currentPointData = data[i];
                let currentX = map(currentPointData.year, minYear, maxYear, chartX, chartX + chartW);
                let currentY = map(currentPointData.gdp, minGDP, maxGDP, chartY + chartH, chartY);

                // Draw connecting line segment if not the first point
                if (i > 0) {
                    let prevPointData = data[i - 1];
                    prevX = map(prevPointData.year, minYear, maxYear, chartX, chartX + chartW);
                    prevY = map(prevPointData.gdp, minGDP, maxGDP, chartY + chartH, chartY);

                    // Determine segment color
                    let segmentColor = primaryColor;
                    if (currentHighlight &&
                        currentPointData.year >= currentHighlight.startYear &&
                        prevPointData.year <= currentHighlight.endYear) {
                        segmentColor = highlightColor;
                    }

                    stroke(segmentColor);
                    strokeWeight(3);

                    // Draw segment based on animation progress
                    if (prevPointData.year < currentAnimationYear) {
                        line(prevX, prevY, currentX, currentY); // Full segment
                    } else if (prevPointData.year === currentAnimationYear && currentAnimationYear <= maxYear) { // Current animating segment
                        let interpolatedX = lerp(prevX, currentX, animationProgress);
                        let interpolatedY = lerp(prevY, currentY, animationProgress);
                        line(prevX, prevY, interpolatedX, interpolatedY);
                    }
                }

                // Draw data point circle only if it's within the drawn animation range
                if (currentPointData.year < currentAnimationYear || (currentPointData.year === currentAnimationYear && animationProgress > 0) || currentPointData.year === maxYear && animationProgress === 1) {
                    fill(primaryColor);
                    if (currentHighlight && currentPointData.year >= currentHighlight.startYear && currentPointData.year <= currentHighlight.endYear) {
                        fill(highlightColor);
                    }
                    stroke(255);
                    strokeWeight(1);
                    ellipse(currentX, currentY, 8, 8); // Data point
                }
            }

            // Draw the current year indicator (large glow) and GDP label
            let activePointData = data.find(d => d.year === currentAnimationYear);
            if (activePointData) {
                let activeX = map(activePointData.year, minYear, maxYear, chartX, chartX + chartW);
                let activeY = map(activePointData.gdp, minGDP, maxGDP, chartY + chartH, chartY);

                // If currently animating a segment, position the glow smoothly along the segment
                if (currentAnimationYear < maxYear && animationProgress > 0 && animationProgress < 1) {
                    let nextPointData = data.find(d => d.year === currentAnimationYear + 1);
                    if (nextPointData) {
                        let nextX = map(nextPointData.year, minYear, maxYear, chartX, chartX + chartW);
                        let nextY = map(nextPointData.gdp, minGDP, maxGDP, chartY + chartH, chartY);
                        activeX = lerp(activeX, nextX, animationProgress);
                        activeY = lerp(activeY, nextY, animationProgress);
                    }
                }

                // Draw glow
                fill(glowColor);
                noStroke();
                ellipse(activeX, activeY, 15, 15);

                // Draw GDP label for the currently active point
                fill(textColor);
                noStroke();
                textSize(chartW * 0.02);
                textAlign(CENTER, BOTTOM);
                let currentDisplayedGDP = activePointData.gdp;
                if (currentAnimationYear < maxYear && animationProgress > 0 && animationProgress < 1) {
                    let nextPointData = data.find(d => d.year === currentAnimationYear + 1);
                    if (nextPointData) {
                        currentDisplayedGDP = lerp(activePointData.gdp, nextPointData.gdp, animationProgress);
                    }
                }
                text(`${nf(currentDisplayedGDP, 0, 1)}%`, activeX, activeY - 15);
            }
        }

        function drawLabels() {
            fill(getComputedStyle(document.documentElement).getPropertyValue('--text-color'));
            textSize(chartW * 0.03);
            textAlign(CENTER, TOP);
            text("India's Annual GDP Growth (2000-2023)", canvasWidth / 2, chartY / 2);
        }

        function resetVisuals() {
            currentAnimationYear = minYear;
            animationProgress = 0;
            currentHighlight = null;
            currentNarrationIndex = 0;
            if (isNarrating) {
                if (utterance) speechSynthesis.cancel();
                isNarrating = false;
                document.getElementById('podcast').textContent = '🔊';
            }
        }

        function toggleNarration() {
            if (isNarrating) {
                if (utterance) {
                    speechSynthesis.cancel();
                }
                isNarrating = false;
                document.getElementById('podcast').textContent = '🔊';
            } else {
                resetVisuals(); // Reset visuals from beginning when starting narration
                isNarrating = true;
                document.getElementById('podcast').textContent = '🔇';
                startNarration();
            }
        }

        function startNarration() {
            if (!isNarrating || currentNarrationIndex >= narrationStatements.length) {
                isNarrating = false;
                document.getElementById('podcast').textContent = '🔊';
                currentHighlight = null; // Clear highlight at end
                currentAnimationYear = maxYear; // Ensure graph is fully drawn
                animationProgress = 1;
                return;
            }

            let statementData = narrationStatements[currentNarrationIndex];
            utterance = new SpeechSynthesisUtterance(statementData.text);

            if (statementData.speaker === 'A') {
                utterance.voice = speakerA;
                utterance.pitch = 1.0;
                utterance.rate = 1.0;
            } else { // Speaker B
                utterance.voice = speakerB;
                utterance.pitch = 0.9;
                utterance.rate = 0.95;
            }

            utterance.onstart = () => {
                currentHighlight = statementData.highlight;
                if (currentHighlight) {
                    // Instantly draw the graph up to the end of the highlighted period
                    currentAnimationYear = currentHighlight.endYear;
                    animationProgress = 1;
                }
            };

            utterance.onend = () => {
                currentNarrationIndex++;
                startNarration(); // Play next statement, or terminate if done
            };

            speechSynthesis.speak(utterance);
        }

        // Override p5's default error handling to prevent disrupting the page
        window.onerror = function(message, source, lineno, colno, error) {
            console.error("An error occurred:", message, "at", source + ":" + lineno);
            return true; // Suppress default browser error handling
        };
    </script>
